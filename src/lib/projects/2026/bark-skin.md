# BarkSkin

2026 | Single-channel video

Is it possible to embodied something as innocuous a natural fibres? This project was spearheaded by  [Juni Neyenhuys](https://www.instagram.com/junisun_/), in collaboration with [Julia Zambrzycki](https://www.instagram.com/agent_julio/). The goal was to produce an animation of a dancing human covered in natural fibres.  The look is inspired by actual real world fibres made from cellulose and tannin (both derived from trees) to create a naturally water-repellent material.

This project used Blender and a custom particle proejction technique inside Touchdesigner to create the animation.
