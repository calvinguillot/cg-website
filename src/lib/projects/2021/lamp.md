# Lamp

2021 | Reeds and 3D Printing

Reed is one of my favourite materials. First because it has a nice color and texture, but also because when properly dried it is sturdy but yet flexible. I have used it in other projects before.

I recently moved to another apartment and needed a new lamp. I have some extra reed lying around for a while now, so I decided that i could use it to create some sort of shade. The final product consists of a 3D printed PLA core, where the reed sticks are attached too. Then using jute fiber, the reeds are woven together.
