# Rauhankone — Ekho Collective

2024–2025 | Interactive immersive installation

Layers in The Peace Machine is an immersive and multidisciplinary media-installation, entangling technology and art. Based on the literary work ”Peace Machine” by late Timo Honkela, the installation portrays peace as a dynamic process, that shifts and evolves with the interaction from the participants. This is an large interactive immersive installation for the [Oulu European Capital of Culture 2026](https://oulu2026.eu/en/). The Peace Machine is located in the Oulu city Hall. It consists of 3 floors with audiovisual interactive installations and a website where the audience can interact with the piece.
